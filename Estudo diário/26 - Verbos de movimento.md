# 26 · Verbos de movimento

| 日本語 | Romaji | 🇺🇸 | 🇧🇷 |
|---|---|---|---|
| 歩く | aruku | walk | andar |
| 走る | hashiru | run | correr |
| 乗る | noru | ride / get on | embarcar / pegar (transporte) |
| 降りる | oriru | get off | descer |
| 入る | hairu | enter | entrar |
| 出る | deru | go out / leave | sair |
| 着く | tsuku | arrive | chegar |
| 止まる | tomaru | stop | parar |

Exemplo: 駅でバスに乗ります。(Eki de basu ni norimasu.) — Pego o ônibus na estação.

## Flashcards
歩く (Aruku)::To walk / Andar
走る (Hashiru)::To run / Correr
乗る (Noru)::To ride, get on / Embarcar
降りる (Oriru)::To get off / Descer
入る (Hairu)::To enter / Entrar
出る (Deru)::To go out / Sair
着く (Tsuku)::To arrive / Chegar
