# 34 · Demonstrativos: これ, それ, あれ, どれ

| Palavra | Distância | 🇧🇷 |
|---|---|---|
| これ (kore) | perto de quem fala | isto |
| それ (sore) | perto de quem ouve | isso |
| あれ (are) | longe de ambos | aquilo |
| どれ (dore) | pergunta | qual? |

| 🇯🇵 | 🇧🇷 |
|---|---|
| これは本です。 | Isto é um livro. |
| それは何ですか。 | O que é isso? |
| あれは私の車です。 | Aquilo é meu carro. |
| 私のかばんはどれですか。 | Qual é a minha bolsa? |

## Flashcards
これ (Kore)::This / Isto
それ (Sore)::That (near you) / Isso
あれ (Are)::That (over there) / Aquilo
どれ (Dore)::Which one / Qual
