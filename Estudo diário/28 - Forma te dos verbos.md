# 28 · Forma て dos verbos

| Grupo | Regra | Exemplo |
|---|---|---|
| る-verbos (grupo 2) | tira る, põe て | 食べる → 食べて |
| う, つ, る | → って | 買う → 買って, 待つ → 待って, 帰る → 帰って |
| む, ぶ, ぬ | → んで | 飲む → 飲んで, 遊ぶ → 遊んで |
| く | → いて | 書く → 書いて (exceção: 行く → 行って) |
| ぐ | → いで | 泳ぐ → 泳いで |
| す | → して | 話す → 話して |
| irregulares | する → して, 来る → 来て | |

## Flashcards
食べる → 食べて (Tabete)::Te-form of eat / Forma て de comer
飲む → 飲んで (Nonde)::Te-form of drink / Forma て de beber
書く → 書いて (Kaite)::Te-form of write / Forma て de escrever
行く → 行って (Itte)::Te-form of go (exception) / Forma て de ir (exceção)
話す → 話して (Hanashite)::Te-form of speak / Forma て de falar
する → して (Shite)::Te-form of do / Forma て de fazer
来る → 来て (Kite)::Te-form of come / Forma て de vir
