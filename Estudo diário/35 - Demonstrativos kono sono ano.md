# 35 · Demonstrativos: この, その, あの, どの

Vêm **antes de um substantivo** (diferente de これ/それ/あれ).

| 日本語 | 🇧🇷 | Exemplo |
|---|---|---|
| この | este | この本 — este livro |
| その | esse | その人 — essa pessoa |
| あの | aquele | あの店 — aquela loja |
| どの | qual | どの本 — qual livro |

| 🇯🇵 | 🇧🇷 |
|---|---|
| この猫はかわいいです。 | Este gato é fofo. |
| あの人は誰ですか。 | Quem é aquela pessoa? |

## Flashcards
この (Kono)::This (+ noun) / Este
その (Sono)::That (+ noun) / Esse
あの (Ano)::That over there (+ noun) / Aquele
どの (Dono)::Which (+ noun) / Qual
あの人は誰ですか (Ano hito wa dare desu ka)::Who is that person? / Quem é aquela pessoa?
