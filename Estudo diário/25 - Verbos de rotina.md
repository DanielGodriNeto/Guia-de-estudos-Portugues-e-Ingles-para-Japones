# 25 · Verbos de rotina

| 日本語 | Romaji | 🇺🇸 | 🇧🇷 |
|---|---|---|---|
| 起きる | okiru | wake up | acordar |
| 寝る | neru | sleep / go to bed | dormir |
| 働く | hataraku | work | trabalhar |
| 休む | yasumu | rest | descansar |
| 帰る | kaeru | return home | voltar para casa |
| 始まる | hajimaru | begin | começar |
| 終わる | owaru | end | terminar |
| 洗う | arau | wash | lavar |

Exemplo: 毎朝六時に起きます。(Maiasa rokuji ni okimasu.) — Acordo às seis toda manhã.

## Flashcards
起きる (Okiru)::To wake up / Acordar
寝る (Neru)::To sleep / Dormir
働く (Hataraku)::To work / Trabalhar
休む (Yasumu)::To rest / Descansar
帰る (Kaeru)::To return home / Voltar para casa
始まる (Hajimaru)::To begin / Começar
終わる (Owaru)::To end / Terminar
